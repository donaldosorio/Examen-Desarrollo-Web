# Pista 1: leer el problema

Antes de editar, sigan una solicitud completa: formulario, navegador, PHP, consulta SQL y respuesta.

Para cada dato, escriban tres cosas:

- ¿Quién lo envía?
- ¿Quién puede modificarlo?
- ¿Debe creerse o debe comprobarse otra vez en el servidor?

Si no pueden responder esas preguntas, todavía no es momento de refactorizar.
